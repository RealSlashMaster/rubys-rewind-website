# Ruby's Kitchen Rewind website

A plain static site. Each `.html` file is a complete page; edit it directly in any editor.

- Pages: `index.html`, `recipes.html`, `about.html`, `gallery.html`, `contact.html`
- The header, menu and footer are repeated in every page. If you change one (for example, add a menu item), change it in all five.
- Styles are in `styles.css`, and photos are in `images/`.

## Preview locally

Double-click `index.html`.

## Before going live

- Replace the `href="#"` social links in `contact.html` with the real Facebook, Instagram, YouTube and TikTok URLs.
- Replace `hello@example.com` in `contact.html` (it appears twice) with the real email address.

## Deploy

Live site: https://rubys-rewind.netlify.app

To publish changes, open the site in Netlify, go to the **Deploys** tab and drag this folder onto the drop box. The link stays the same.
